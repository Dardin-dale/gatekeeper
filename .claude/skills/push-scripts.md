# /push-scripts - Push Script Updates to a Running Server

Update `scripts/game/` on a running instance without a full redeploy. The instance syncs scripts +
`game-profile.json` from `s3://<backup-bucket>/scripts/game/` via `update-gatekeeper-scripts.service`.

## When to use

After editing `scripts/game/*.sh` while the server is up and you don't want a full `cdk deploy`.
(Note: `game-profile.json` is regenerated by CDK, so profile changes still need a deploy.)

## Steps

1. Find the bucket:
   ```bash
   BUCKET=$(aws cloudformation describe-stacks --stack-name GateStack-AbioticFactor \
     --query 'Stacks[0].Outputs[?OutputKey==`BackupBucketName`].OutputValue' --output text)
   ```
2. Upload the changed scripts:
   ```bash
   aws s3 sync scripts/game/ "s3://$BUCKET/scripts/game/" --exclude "*" --include "*.sh" --include "*.js"
   ```
3. Re-run the sync + restart the services on the instance via SSM:
   ```bash
   INSTANCE_ID=$(aws cloudformation describe-stacks --stack-name GateStack-AbioticFactor \
     --query 'Stacks[0].Outputs[?OutputKey==`InstanceId`].OutputValue' --output text)
   aws ssm send-command --instance-ids "$INSTANCE_ID" --document-name "AWS-RunShellScript" \
     --parameters 'commands=["systemctl restart update-gatekeeper-scripts.service","systemctl restart game-server.service game-monitor.service"]'
   ```

## Notes

- Restarting `game-server.service` restarts the container — players disconnect briefly.
- Replace `GateStack-AbioticFactor` with the right `GateStack-<Pascal>` for other games.
